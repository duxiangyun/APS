## 1.4 角色与权限现状

**结论：当前 APS 代码中无角色概念——当前无角色控制。**

代码证据（只读扫描确认）：
1. `aps/src/web/app/` 全部 `.py`/`.html` 中 grep `role` / `login` / `permission` / `current_user` / `require_role` / `密码` / `logout` 均无匹配。
2. `main.py` 仅挂载 13 个业务 router，无认证中间件、无 Session/Cookie 校验。
3. 所有页面路由（`/dashboard`、`/solve`、`/api/edit/*` 等写接口）均**无鉴权**，任何访问者可读写。
4. 数据库 `aps_or.db` 中查询 `sqlite_master`：**无用户表、无角色表、无权限表**（表名含 `user`/`role`/`perm` 的 0 张），全部表为 `stg_*`/`core_*`/`alg_*`/`res_*`/元数据表。

| 项 | 结构/字段 | 说明 |
|---|---|---|
| 用户表 | **不存在** | 无 |
| 权限表 | **不存在** | 无 |
| 操作日志表 | **不存在** | 无 |

对照：**角色控制现状（2026-09-26 更新）**：`agent/app/role_config.py` 的 `ROLE_KEYS` 已扩展为 **9 个**（`planner/supervisor/manager/analyst/purchaser/masterdata/sales/admin/default`），按角色过滤工具白名单与输出风格；APS 侧 `app/constants.py::ROLE_MENUS` 定义同一套 9 角色的菜单可见性，由 `static/js/role_control.js` 在页面加载时按 `?role=` 应用（iframe 内跳转经 sessionStorage 记住角色）。统一壳（`web/src/App.tsx` + `hooks/useAppShell.tsx`）为角色唯一真源：切换角色同时驱动 Agent 对话（`/chat/stream`、`/skills` 带 `role`）与 APS iframe（`src="/aps/dashboard?role=<role>"` 重新加载）。**仍缺**：用户表/会话与按钮级写操作鉴权——当前角色控制为前端菜单可见性 + Agent 工具白名单，直接请求 APS 写接口不会被拒绝。9 角色权限矩阵见产品规划文档 6.4 节。

## 1.5 关键结论

1. **一级菜单共 13 个**：工作台、排产助手、计划优化、排程可视化、分析中心、计划版本、业务数据、基础数据、系统管理、项目文档、开发工具、场景管理（禁用）、集成管理（禁用）。**启用 11 个**。
2. **每个菜单下的可用页面数**：

| 菜单 | 可用页面数 | 备注 |
|---|---|---|
| 工作台 | 1 | `/dashboard` |
| 排产助手 | 1 | `/agent`（含 4 组 `/api/agent/*`） |
| 计划优化 | 3 | solve / params / whatif |
| 排程可视化 | 8 | 7 个 `/vis/*` + `/res/equip_load` |
| 分析中心 | 5 | delay/bottleneck/inventory/cost/outsource |
| 计划版本 | 2 | versions / versions_compare |
| 业务数据 | 11 | 总览 + 10 表（BOM 走可视化页） |
| 基础数据 | 11 | 总览 + 10 表 |
| 系统管理 | 1 | 数据校验 |
| 项目文档 | 1 | 文档中心（+ `/docs/view` 渲染） |
| 开发工具 | 56 | 工具总览 1 + 原始数据 14 + 算法输入 14 + 输出结果 27 |
| 场景管理 | 0 | 菜单禁用 |
| 集成管理 | 0 | 菜单禁用 |
| **合计** | **100** | 另有 `/docs/view`、`/api-docs`、`/open/*` 等非菜单入口 |

3. **已跑通的核心功能**：
   - 数据链路闭环：Excel 导入（`import_excel_to_stg.py`）→ stg→core ETL → alg 视图 → Gurobi 求解 → 26 个 `res_view_*` 结果视图 → Web 展示，库内已有 28 个求解批次；
   - 排产触发与状态监控（`/solve`，子进程 + 日志轮询）；
   - 25 项排产参数/约束开关/目标权重在线配置（`/params`）+ 16 张 core 表白名单 CRUD；
   - What-if 沙盒全链路（场景→沙盒求解→自动恢复→基线对比）；
   - 8 个可视化看板 + 5 个分析页 + 2 版本对比 + 12 项数据校验；
   - 工作台 KPI/告警、Agent 对话助手（工具白名单 + 写操作确认）、开放 REST API、文档中心。
4. **半成品**：
   - 系统管理：仅数据校验，用户/角色/日志三无（规划 46/47/48）；
   - 计划版本：有列表与对比，无审批/发布/冻结工作流；
   - 开发工具：工具总览 5 个入口中 3 个 `planned`（求解器对比、ETL 导入验证、模型一致性检查）；
   - 场景管理、集成管理：菜单存在但 `enabled=False`，纯占位。
5. **空白**：用户登录与角色权限、增量排产、工厂日历、计划与实绩对比、ERP/MES 对接、消息通知、CTP 交期承诺、甘特拖拽调整。
