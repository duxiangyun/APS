### 约束逻辑说明

**产品库存平衡约束 `ProdBal`**（[L941-953](file:///Users/duxiangyun/PythonProjects/APS/src/model/APS-SPlant-v2-sqlite.py#L941-L953)）：

```
前期库存 - 当期库存 + 不可行 + 本期生产(Σ各工艺路线) - 本期销售 - 替代出 + 替代入 = 0
```

**自制品库存平衡约束 `Self1Bal`**（[L962-987](file:///Users/duxiangyun/PythonProjects/APS/src/model/APS-SPlant-v2-sqlite.py#L962-L987)）：

```
前期库存 - 当期库存 + 不可行 + 本期生产 - 上级产品消耗 - 上级自制品消耗 + 外协补充 = 0
```

**原材料库存平衡约束 `RawBal`**（[L997-1002](file:///Users/duxiangyun/PythonProjects/APS/src/model/APS-SPlant-v2-sqlite.py#L997-L1002)）：

```
本期采购(提前期偏移) + 前期库存 - 当期库存 + 不可行 - 上级自制品消耗 = 0
```

**设备能力平衡约束 `CapBal`**（[L1015-1027](file:///Users/duxiangyun/PythonProjects/APS/src/model/APS-SPlant-v2-sqlite.py#L1015-L1027)）：

```
加工量 ≤ 正常能力 + 加班能力 + 不可行松弛
```

## 三、目标函数

**最大化生产利润**（[L845-861](file:///Users/duxiangyun/PythonProjects/APS/src/model/APS-SPlant-v2-sqlite.py#L845-L861)）：

```
利润 =   销售收入                  (+ OrdPrice × OrdSale)
       - 延迟交付成本              (- OrdFine × OrdDelay)
       - 原材料采购成本            (- RawCost × Purchase)
       - 外协件采购成本            (- OutsCost × OutSourc)
       - 工艺加工成本              (- EquipCost × Workload + EquipCost × EquipOverR × Overload)
       - 模具使用成本              (- FixtCost × Fixtload + FixtCost × Fovcost × FixtPlus)
       - 产品库存成本              (- ProdInvCost × ProdInv)
       - 自制件库存成本            (- SelfInvCost × SelfInv)
       - 原材料库存成本            (- RawInvCost × RawInv)
       - 不可行罚成本              (- penalty × Σ Inf 变量)
       - 替代惩罚                  (- 0.000001 × Substi)
```

## 四、对偶解（影子价格）

仅在 `intager == 0`（连续松弛）时提取（[L1156-1179](file:///Users/duxiangyun/PythonProjects/APS/src/model/APS-SPlant-v2-sqlite.py#L1156-L1179)）：

| 对偶变量 | 来源约束 | 计算方式 | 经济含义 |
|---|---|---|---|
| `Proddual[i,t]` | `ProdBal[i,t]` | `-ProdBal[i,t].Pi` | 最终产品边际生产成本 |
| `Self1dual[i,t]` | `Self1Bal[i,t]` | `-Self1Bal[i,t].Pi` | 自制品边际生产成本 |
| `Rawdual[i,t]` | `RawBal[i,t]` | `-RawBal[i,t].Pi` | 原材料边际价值 |
| `Equipdual[i,t]` | `CapBal[i,t]` | `CapBal[i,t].Pi` | 设备能力边际价值 |
| `Fixtdual[i,t]` | `FixtBal[i,t]` | `FixtBal[i,t].Pi` | 工装能力边际价值 |

> **取负号说明**：`ProdBal`/`Self1Bal`/`RawBal` 是等式约束（`== 0`），Gurobi 对偶符号 convention 需要翻转。`CapBal`/`FixtBal` 是不等式约束（`<=`），无需翻转。

## 五、边际贡献

**计算公式**（[L1266-1269](file:///Users/duxiangyun/PythonProjects/APS/src/model/APS-SPlant-v2-sqlite.py#L1266-L1269)）：

```
边际贡献 = 订单单价 - 产品影子价格
Marjin   = OrdPrice - Proddual[产品索引, 周期]
```

| 场景 | 影子价格取值周期 | 行号 |
|---|---|---|
| 已交付订单 | 实际交付周期 t | [L1267-1268](file:///Users/duxiangyun/PythonProjects/APS/src/model/APS-SPlant-v2-sqlite.py#L1267-L1268) |
| 未交付订单 | 订单交期 `OrdTime[i]` | [L1286-1288](file:///Users/duxiangyun/PythonProjects/APS/src/model/APS-SPlant-v2-sqlite.py#L1286-L1288) |

### 经济含义

| 值 | 含义 | 决策建议 |
|---|---|---|
| `Marjin > 0` | 订单价格 > 边际成本，接单有利可图 | 优先排产 |
| `Marjin ≤ 0` | 订单价格 ≤ 边际成本，接单不赚钱甚至亏本 | 谨慎评估 |

> **前提条件**：边际贡献仅在 `intager == 0`（连续松弛）时输出，因为整数规划的对偶值无经济学意义。

### 数据流说明

```
采购 → 原料库存 → 自制品生产 → 自制品库存 → 产品生产 → 产品库存 → 订单交付
```

**不可行变量**（`*Inf`）：松弛项，当约束无法满足时吸收差额，目标函数中以高额 `penalty` 惩罚，确保模型始终有解。

**替代变量**（`Substi`）：允许用一种物料替代另一种物料，在库存不足时提供灵活性，但目标函数中有微小惩罚（`0.000001`）以避免过度替代。

**外协变量**（`OutSourc`）：当自制产能不足时，允许将自制品外协生产，受分周期限额约束。
